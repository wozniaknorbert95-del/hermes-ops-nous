Moduł 1 — Fundament: Git, własny GitLab, CI Tydz. 1

🎯 Umiesz po module

Wyjaśnisz „source of truth”, stawiasz i zabezpieczasz własny GitLab CE, robisz MR przez zielone CI. Bez tego nie ma labu dla agentów.

📚 Biblioteka (~45 min, można na raty)

  • cursor-kurs/00 — START + słownik 15′
  • cursor-kurs/01 — model myślenia 10′
  • handbook/02 — rozdz. 1–2 (Git, host) 10′
  • handbook/05 — GitLab CE §1–4 15′ instrukcja

🧪 Laboratorium (zaznaczaj wykonane)

🏅 Artefakt (dowód w GitLabie albo GitHub Actions)

Zielony pipeline + zmergowany MR #1 w workflow-lab. Zrób zrzut — pierwszy dyplom. Nie commituj tego do platformy.

Tor F — mapa na Kokpit

Merge = human-stop właściciela (Taca). Zespół → szkolenia = skill workerów, nie ta akademia. Zero 7. działu.

✅ Checkpoint — odpowiedz szczerze

1. Potrafię w 2 zdaniach wyjaśnić, czym jest „source of truth” i dlaczego laptop nim nie jest.
2. Potrafię samodzielnie zrobić: branch → zmiana → MR → czytanie wyniku pipeline.
3. Wiem, gdzie trzymam sekrety CI, a gdzie ich NIGDY nie trzymam.
4. Wymienię z pamięci 3 elementy hardeningu mojego GitLaba CE.
5. Gdy pipeline pada, wiem gdzie patrzę najpierw (log joba) i co to znaczy „parity rule”.
Jeśli „JESZCZE NIE”: powtórz tylko jeden najsłabszy krok labu (nie całość!) i zapytaj Sztaba: prompt A1 z 03-PROMPTY-SZTABU.

Screenshot pętli „z ulicy” na workflow-lab: issue → MR → merge. Laptop zamknięty.
